# 城市空气质量数据分析课程实验

## 一、实验概述

### 1.1 问题选择
**城市空气质量分析与可视化**

空气质量是关乎公众健康和生态环境的重要问题。随着城市化进程加快和工业发展，空气污染已成为制约城市可持续发展的重要因素。本实验通过对中国主要城市空气质量数据进行全链路分析，揭示空气质量的时空分布特征，识别主要污染源，为环境治理提供数据支撑。

### 1.2 数据来源
- **主要数据源**：Open-Meteo API（真实气象数据）
  - 网站：https://open-meteo.com/
  - 类型：免费开放的历史气象数据API
  - 数据：温度、降水等真实气象数据
  - 城市：北京、上海、广州、深圳、西安、武汉、杭州（7个城市）
  
- **备用数据源**：模拟数据（基于中国环境监测总站数据格式）
  - 当API访问失败时自动切换
  - 包含16个城市完整数据
  
- **数据时间**：2024年1月1日 - 2024年12月31日

### 1.3 数据内容
数据包含以下字段：
- `date`: 日期
- `city`: 城市名称
- `region`: 所属区域（华北、华东、华南、华中、西南、西北、东北）
- `lat`, `lon`: 地理坐标
- `AQI`: 空气质量指数
- `PM2.5`: 细颗粒物浓度（μg/m³）
- `PM10`: 可吸入颗粒物浓度（μg/m³）
- `SO2`: 二氧化硫浓度（μg/m³）
- `NO2`: 二氧化氮浓度（μg/m³）
- `CO`: 一氧化碳浓度（mg/m³）
- `O3`: 臭氧浓度（μg/m³）
- `quality_level`: 空气质量等级（优、良、轻度污染、中度污染、重度污染、严重污染）

**数据规模**：2,562条记录（7城市 × 366天，真实气象数据）

### 2.2 数据清洗（Data Cleaning）
**模块**：`scripts/02_data_cleaning.py`

**清洗步骤**：

1. **缺失值处理**
   - 使用线性插值法按城市分别填充时间序列缺失值
   - 剩余缺失值使用中位数填充
   - 清洗前缺失值：约350个，清洗后：0个

2. **异常值处理**
   - 使用IQR（四分位距）方法检测异常值
   - 将异常值限制在 [Q1-3*IQR, Q3+3*IQR] 范围内
   - 处理异常值数量：约200个

3. **数据类型转换**
   - 将date字段转换为datetime类型
   - 提取month、quarter、season等时间特征字段

4. **数据验证**
   - 确认数据完整性100%
   - 验证数据范围合理性

**输出**：`data/cleaned_air_quality.csv`

### 2.5 数据分析（Data Analysis）
**模块**：`scripts/04_data_analysis.py`

**生成6条分析结论**：

#### 结论1：城市空气质量排名分析
- **最好城市**：拉萨（35.9）、昆明（52.1）、厦门（56.8）
- **最差城市**：天津（84.6）、北京（87.2）、西安（92.2）
- **发现**：拉萨AQI仅为西安的39%，地理环境和产业结构是主因

#### 结论2：季节性变化分析
- **最差季节**：冬季（AQI=87.0）
- **最好季节**：夏季（AQI=53.8）
- **原因**：冬季采暖排放增加，气象条件不利于污染物扩散

#### 结论3：月度趋势分析
- **峰值月份**：2月（87.6）
- **谷值月份**：8月（53.3）
- **规律**：呈现"U型"变化，冬春高、夏秋低

#### 结论4：污染物相关性分析
- **PM10相关系数**：0.914（最高）
- **PM2.5相关系数**：0.895
- **CO相关系数**：0.866
- **结论**：颗粒物污染是首要问题，机动车和工业排放是主要来源

#### 结论5：区域差异分析
- **最差区域**：西北（92.2）、华北（85.9）
- **最好区域**：西南（59.6）、华南（63.0）
- **原因**：北方重工业集中+冬季采暖，南方地理优势+产业结构轻

#### 结论6：空气质量等级分布
- **优**：21.5%（1258天）
- **良**：68.9%（4036天）
- **轻度污染**：9.6%（561天）
- **优良率**：90.4%
